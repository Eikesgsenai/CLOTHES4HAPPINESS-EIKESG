# Módulo Producao

Responsável pela gestão completa dos processos fabris, desde a programação das máquinas até o controle de qualidade e a automação da produção no chão de fábrica.

**Usuários:** Gerentes de Produção, Operadores de Fábrica, Analistas de Qualidade
**Sistema(s):** Sistema de Execução de Manufatura (MES), Sistema de Relatórios de Produção
