# Módulo Financeiro

Responsável pelo controle financeiro da empresa. Gerencia o fluxo de caixa, as contas a pagar e a receber, o faturamento e gera relatórios para análise de desempenho e tomada de decisões.

**Usuários:** Analistas Financeiros, Gerentes Financeiros, Diretores
**Sistema(s):** Sistema Integrado de Gestão Empresarial (ERP), Sistema de Análise de Custos e Desempenho Financeiro
