# Módulo Vendas

Responsável pela gestão do ciclo de vendas, desde o primeiro contato com o cliente até o faturamento. O objetivo é fortalecer o relacionamento e otimizar o controle de pedidos.

**Usuários:** Equipe de Vendas, Gerentes de Vendas, Equipe de Suporte ao Cliente
**Sistema(s):** Sistema de Controle de Pedidos e Faturamento, Sistema de Gestão de Relacionamento com o Cliente (CRM)
