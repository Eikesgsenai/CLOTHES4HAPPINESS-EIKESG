# Módulo Rh

Responsável pela gestão de pessoas. O departamento cuida desde a folha de pagamento e o recrutamento até o desenvolvimento de talentos e a avaliação de desempenho dos funcionários.

**Usuários:** Analistas de RH, Gerentes de RH, Funcionários (para acesso a informações pessoais)
**Sistema(s):** Sistema de Gestão de Folha de Pagamento, Sistema de Gestão de Talentos
