# Módulo Estoque

Responsável pela gestão de todos os materiais e produtos acabados. O foco é na otimização do armazenamento, rastreamento de produtos e na previsão de demanda para evitar excesso ou falta de itens.

**Usuários:** Analistas de Estoque, Gerentes de Armazém
**Sistema(s):** Sistema de Gestão de Armazém (WMS), Sistema de Previsão de Demanda
